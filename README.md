# Super Cloudbuilt Randomizer for Archipelago
This is a randomizer implementation for [Super Cloudbuilt](https://store.steampowered.com/app/463700/Super_Cloudbuilt/) for use in [Archipelago](https://archipelago.gg/). It is implemented using [Manual for Archipelago](https://github.com/ManualForArchipelago/Manual) version "Stable - 20260319" 

# Reporting Bugs
If you find any errors in the randomizer logic (impossible checks, etc) or world generation, please let me know by opening an issue.
